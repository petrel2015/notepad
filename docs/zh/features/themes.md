# 主题系统设计

> 当前已有本地初版。本文保留目标设计，实施状态与偏差以[当前实现与验收](../implementation.md)为准；下文“未实现/待开始”是初始规划基线，不代表当前代码。

## 概述

状态：Planned。黑白内置主题与自定义主题使用相同的版本化 JSON。

## 背景

用户明确要求 JSON 文件、导入导出和 localStorage 持久化。

## 问题

界面、编辑区和 diff 若分别硬编码颜色，会导致切换主题不一致。

## 目标

整个界面统一主题；可预览/应用/复制/重命名/删除自定义主题；刷新恢复；导出导入等价。

## 非目标

不允许主题执行代码、注入任意 CSS 或加载外部图片/字体；首版不做主题云同步。

## 方案概览

导入 → 结构及字段白名单校验 → 按 base 补齐 → 映射界面/编辑器令牌 → 预览/应用 → 持久化。内置主题也使用 JSON 文件，应用内持久化副本使用同一契约。

## 详细行为

以下为格式草案，不是已实现 API：

```json
{
  "version": 1,
  "id": "custom-night",
  "name": "Custom Night",
  "base": "dark",
  "colors": {
    "ui.background": "#181818",
    "ui.foreground": "#eeeeee",
    "editor.background": "#181818",
    "editor.foreground": "#eeeeee",
    "editor.selection": "#365578",
    "diff.addedBackground": "#23452f"
  }
}
```

`version` 是主题格式版本，不是产品版本；首个格式拟为 1，未知版本拒绝。`id` 为稳定标识；`base` 只允许 `dark`/`light`。元数据长度、主题文件大小和颜色数量应有上限，具体数值在实现前冻结。颜色首版仅接受十六进制 `#RRGGBB` 或 `#RRGGBBAA`，未知字段、未知令牌、危险键均拒绝，错误显示字段路径。

缺少颜色继承内置 base；禁止循环继承。内置主题保留不可删除，可复制后修改。同 ID 导入提示覆盖或另存，不静默覆盖。导出包含补齐后的颜色和版本。候选颜色组包括 ui 背景/文字/边框/按钮/面板/标签/状态栏；editor 行号/光标/当前行/选区/搜索/空白标记/缩进线；syntax 各类别；diff 新增/删除/修改的背景与文字。

拟用 `notepad.themes.v1` 存自定义主题列表，`notepad.preferences.v1` 存活动主题 ID。读取校验、写入捕获异常；保存失败时仍可临时应用并导出，不能显示已持久化。损坏数据回退到内置主题，避免未经用户操作覆盖原损坏值。

## 使用体验

默认提供黑、白两种；首次默认建议白色，可一键切换。主题管理展示名称和预览。首次默认色尚待产品确认。

## 兼容性与历史影响

无历史主题数据需要迁移。将来格式升级需显式迁移，保留导出恢复路径，不静默解释未知版本。

## 数据与隐私影响

localStorage 只持久化主题和偏好，不存文件正文；清理浏览器站点数据会删除主题。此为设计要求，尚未验证。

## 性能影响

主题应为小型配置；批量校验后一次应用，避免反复重建编辑器。无性能实测。

## 当前限制

尚无主题编辑界面、实际令牌全集、JSON Schema 或迁移实现；正式 schema 与代码必须使用同一来源。

## 发布信息

Introduced: 未发布；Status: Planned。
