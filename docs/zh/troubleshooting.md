# 预期故障处理

产品已有本地初版。下表为排查指南；实际发现并修复的问题见[验收记录](implementation.md)。

| 场景 | 排查与预期处理 |
| --- | --- |
| 文件乱码 | 检查编码/BOM，允许重新选择编码；不静默保存错误解码结果 |
| 超大结果无法导出 | 检查流式写入能力和权限；不退回无限内存拼接 |
| 写入失败或磁盘不足 | 中止输出、保留源文件，清理或标明未完成目标 |
| 取消后仍出现结果 | 检查任务 ID/修订过滤与取消状态，禁止旧结果覆盖新结果 |
| 主题导入失败 | 显示 JSON/字段路径错误，保持当前主题 |
| 刷新主题丢失 | 检查存储拒绝/配额/损坏；回退并允许导出，不声称保存成功 |
| 搜索很慢或结果很多 | 显示进度、允许取消，结果窗口限量，总计持续更新 |
| diff 合并位置异常 | 检查文档修订，废弃过期 diff 后重新计算 |

问题报告附浏览器版本、模式、字节规模、操作步骤、错误码及脱敏诊断。可用合成样本复现时优先使用合成样本。
