# 实现阶段与验收

> 当前已有本地初版。本文保留目标设计，实施状态与偏差以[当前实现与验收](implementation.md)为准；下文“未实现/待开始”是初始规划基线，不代表当前代码。

所有阶段待开始，文档完成不代表产品完成。依赖顺序为 1 → 2 → 3/4 → 5 → 6；第 1 阶段必须提前验证大文件风险。

| 阶段 | 交付 | 通过条件 |
| --- | --- | --- |
| 1 技术验证 | 编辑组件对比、读写能力矩阵、大文件原型、决策记录 | 中文组合输入不误触快捷键；验证跨块解码/匹配、磁盘写入和超长行；记录环境和实测数据 |
| 2 基础编辑 | 文件与标签、编辑保存、状态栏、可见字符 | 打开保存往返正确，撤销可靠；IME Enter 正常；计数覆盖 emoji/组合字符/Tab/CRLF/选区边界 |
| 3 主题 | 黑白 JSON、管理、导入导出、持久化 | 全界面一致；刷新恢复；导出导入等价；恶意字段、损坏数据、配额错误有回退 |
| 4 查找与工具 | 普通查找替换、正则、JSON、基础整理 | 错误不改原文；批量操作可撤销；大整数不损失精度；病态正则可终止 |
| 5 对比 | 行级/行内 diff、跳转、合并 | 增删改结果正确；过期 diff 不可写入；双向合并可撤销；忽略规则不改原文 |
| 6 大文件与整体验收 | 流式浏览、全局查找、替换导出 | 输入输出内容、匹配次数与独立基准一致；进度/取消/失败正确；缓存及队列有界 |

## 性能验证

100 MB 和 1 GB 是建议测试档位，不是已支持容量。使用可复现生成器创建普通多行、超长单行、密集匹配、跨块关键词、中文及混合换行样本，保存 seed、字节数与校验值。大样本临时生成，不提交仓库。

记录硬件、系统、浏览器版本、提交版本、首次可见时间、索引与搜索耗时、峰值内存、取消响应、输出字节数和校验值。冷/热缓存分开记录。阶段 1 根据基线冻结数值门槛，再作为后续验收标准；不得事后放宽门槛来声称通过。

## 可重复交付

Hermes 每次接收一个边界清晰的任务，交付改动摘要、检查命令、实际结果、失败样本及结构化诊断。确定性算法用代码测试，浏览器权限和体验用真实浏览器验证。独立审查后修复具体缺陷，不以实现者的“通过”替代验收。

完成条件：需求 ID 对应证据；已知限制可见；文档与实现一致；无阻塞缺陷。上线和公开发布不包含在本次文档任务中。
