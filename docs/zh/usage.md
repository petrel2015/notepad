# 使用指南

先按 [README](../../README.zh.md) 启动本地应用。

1. **编辑**：点击新建直接输入；“打开文件”优先原生文件句柄，“导入”提供兼容选择器，也可拖入文件。多文件进入独立标签，关闭修改过的标签会提醒。保存作用于当前编辑窗格；兼容下载只能确认已发起下载，保留修改标记。
2. **查找替换**：打开面板（⌘/Ctrl+F），输入条件与替换内容，点击查找，再执行当前/全部替换。选区搜索先选择文字再勾选“仅选区”。条件或原文变化后须重新查找。普通文件超过 20,000 个匹配时禁止部分全部替换；正则超时会终止。
3. **显示**：点击可见字符同时显示空格、Tab 和行尾标记；这些不进入保存。自动换行只改变显示。跳转接受行号或“行号:列号”。状态栏字符按码点、列从 1 开始。
4. **JSON/整理**：文本工具选择格式化、压缩、校验或行整理。操作可撤销；语法或重复键错误保留原文，大数字词法不改变。
5. **对比**：打开两个普通文本后点击双文本对比，选择右侧标签；中央箭头合并单处差异，合并方向按钮切换左右。撤销作用于最近编辑的窗格，保存同样如此。
6. **主题**：◐ 切换黑白；主题设置可复制主题、直接修改 JSON 的 name/colors、应用和导出。修改内置主题须换一个 id。同 ID 自定义主题覆盖前确认。localStorage 拒绝时临时生效并提示，导出可备份。
7. **大文件**：超过 16 MiB 自动分块只读。上一块/下一块浏览；全局查找扫描全文，结果只列前 200 处可点击字节位置。取消可停止任务。替换另存需原生打开源文件取得句柄，目标不得与源相同。兼容导入不具备该安全条件，不提供无限内存下载作为替代。

混合换行文件先只读保留原文，点击提示条可显式转换为 LF 后编辑。仅支持 UTF-8；无法解码会报错。未保存正文不持久化，刷新会丢失。完整边界与验收见[当前实现](implementation.md)。
