## 计数与显示规则（拟议）

行列从 1 开始；空文档为 1 行；末尾换行产生空的末行。CRLF 算一个逻辑换行。视觉折行不增加逻辑行数。字符数默认按 Unicode 码点计数，字节数独立显示；组合字形计数暂不承诺。Tab 算一个字符，显示宽度可设。逻辑列与可视列应明确区分，编辑组件的 UTF-16 偏移必须转换。选区行数按实际覆盖的逻辑行统计，结束位置位于下一行列 1 时不把该行算入。所有可见标记仅用于展示，不进入复制或保存结果。

大文件统计显示扫描中和已扫描范围；完成前不宣称准确全文计数。英文单词数、中文字数、多关键词多色高亮、多光标与矩形选择为后续候选。

## 范围边界

首版大文件不支持交互式任意编辑、完整 diff、全文 JSON 格式化及无限跨行正则。普通文件正则也必须可取消或超时；全词的 Unicode 边界规则需通过验证后冻结。保留混合换行原样，转换须显式触发。

UTF-8 为首个验证路径；UTF-16、GBK/GB18030 的识别、解码、编码保存分开验收，不能从可读推出可写。模式阈值、浏览器矩阵、准确性能目标尚待验证。
