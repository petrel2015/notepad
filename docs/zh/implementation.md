# 当前实现与验收记录

Chrome 扩展改造与安装见 [扩展指南](extension.md)。

2026-10-28，本地初版，未发布。此页描述当前代码；需求和架构草案保留完整目标，不表示所有目标已完成。

## 已实现

- 多标签新建、UTF-8 打开/拖拽/兼容导入、另存、未保存提醒、撤销/重做。
- 行列与选区计数、行数/码点数/UTF-8 字节数；换行折行、行列跳转、空格/Tab/行尾标记。
- 普通文本查找高亮、匹配计数和跳转、选区搜索、大小写/Unicode 全词、正则、单处/全部替换；查找 Worker 超时 2 秒终止。
- JSON 格式化、压缩、校验，保留原数字词法，拒绝重复键；行排序、去重、删空行和清理行尾空白。
- CodeMirror 双文本行级/行内对比、同步滚动、差异跳转、切换双向合并、合并撤销，退出对比保留历史。
- 黑白 JSON 主题、自定义 JSON 编辑、导入导出、复制/改名/删除、字段校验及 localStorage 持久化。
- 大于 16 MiB 自动进入大文件模式：64 KiB 左右窗口分页、完整固定文本搜索、前 200 处字节定位、进度/取消；独立 Worker 支持流式替换写入新文件。

## 实现边界

- 仅 UTF-8；普通文件保留 BOM 与统一 LF/CRLF/CR。混合换行文件只读保留原文，显式转换为 LF 后才能编辑。不是逐行保留混合换行的编辑器。
- 大文件只支持固定文本、区分大小写；不支持全词、正则、全局行号/精确字符统计、任意编辑、diff 或 JSON 格式化。窗口可从匹配位置开始，不是完整虚拟行索引。
- 大文件查找/替换串各限 65,536 个 UTF-16 单元；输入块 256 KiB，输出按阈值冲刷并等待写入。极端扩张输出仍可能填满磁盘；写入失败会尝试 abort。
- 原生另存需浏览器支持文件选择和可写句柄。大文件必须通过“打开文件”取得源句柄，以检查目标不是原文件；“导入”/拖拽可浏览和搜索，但无法直接执行安全另存替换。
- 普通搜索最多保留 20,000 个匹配，仍统计总数；超过时拒绝部分“全部替换”。正则替换支持 `$$`、`$&`、`$1`–`$99`，不支持命名组替换、前后缀引用。选区边界作为搜索边界。
- 普通替换结果最多 16 Mi 个 UTF-16 单元，保存输出最多 32 MiB。普通 JSON/整理操作在主线程运行，尚未完成大普通文件交互延迟验收。
- diff 尚无忽略大小写/空白/换行选项及相同行折叠；未做宽文件对比性能验收。草稿恢复、编码转换、多光标专用 UI、独立可见字符开关、Tab 宽度设置尚未交付。
- 主题颜色令牌以 `src/themes/light.json` 为当前全集。完整 JSON Schema 文件、分离预览和自动迁移未实现；未知版本拒绝。

## 验证中发现并修复

- 逐块无条件让出任务导致细粒度测试超时：改为按时间预算让出，保留取消检查；失败记录保留在本地执行日志。
- UTF-8 分页边界可能漏掉跨界字符：窗口向前校准到码点起点，增加相邻窗口拼接回归测试。
- 对比与普通视图切换需剥离旧 merge 扩展并保留历史状态，已验证退出后编辑和撤销。

Hermes 委派尝试遇到更新依赖下载失败，随后网关会话长时间无代码产出；已通过会话中断接口停止，由 Codex 接手本次实现。未修改 Hermes 全局配置；这不是对 Hermes 可用性的长期结论。
