# 大文件处理设计

> 当前已有本地初版。本文保留目标设计，实施状态与偏差以[当前实现与验收](../implementation.md)为准；下文“未实现/待开始”是初始规划基线，不代表当前代码。

## 概述

状态：Planned。提供分块浏览、全局固定文本查找与替换导出。

## 背景

用户希望借鉴桌面大文件编辑器体验，并补充全局查找替换。

## 问题

一次加载全文、渲染全部行或保存所有匹配位置都可能耗尽内存。

## 目标

缓冲与队列有界；跨块匹配无遗漏；结果准确；任务可取消；原文件保留。

## 非目标

首版不提供任意位置编辑、任意正则、大文件 diff、全文 JSON 格式化。

## 方案概览

文件分块 → 增量解码 → 稀疏行索引/窗口视图；查找扫描全文；替换逐块变换后写入独立目标。

## 详细行为

UTF-8 优先验证。BOM、非法编码、混合换行策略必须显式；非法解码不静默写入替代字符。跨块保留解码状态及匹配所需尾部，关键词可跨换行。空查找串拒绝；按从左到右非重叠匹配，替换串按字面量处理，不解释 `$1`。例如 `aaa` 中用 `aa` 替换为 `b` 得到 `ba`。替换串可以为空，不对生成内容再次替换。

大小写不敏感与全词匹配需冻结 Unicode 规则及原文位置映射。全文统计与界面结果列表分离，结果列表限量/分页，仍准确累计匹配总数。查找高亮只覆盖视口。输入修改或条件变化使旧任务失效。

必须拒绝输出目标与原文件相同。开始写入前取得输出能力与权限，支持背压。读写/编码错误时中止并尝试清理目标；若无法清理则明确标为未完成。完成以写入关闭成功为准，提供输入/输出字节数、替换次数，可重新打开结果。源文件被外部修改时检测并中止或要求重新打开，不能悄悄混用内容。

显示当前模式、可用功能、阶段与字节进度、已发现次数和取消按钮。索引未完成时，尚未可用的行跳转应解释原因。

## 兼容性与历史影响

没有历史实现。流式磁盘输出能力不足时禁止超大导出；仅对有明确大小上限的小结果提供内存下载。浏览器矩阵待验证。

## 数据与隐私影响

设计要求：文件内容不上传，不写入 localStorage；只请求用户选择文件和输出所需权限，诊断不含文本。尚未通过代码验证。

## 性能影响

输入块、输出队列、稀疏索引、窗口和结果列表均需预算。100 MB/1 GB 为测试档位；无性能实测。超长行分段，不能按整行无限缓存。

## 当前限制

未实现；编码写入、全词语义、流式输出及性能上限待验证。
