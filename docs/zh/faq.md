# 常见问题

- **能运行了吗？** 可以，见 README 本地启动命令；尚未发布。
- **多大的文件已经验证？** 浏览器全局查找通过 100 MiB 和 1 GiB 合成样本，不是所有文件/设备的容量保证。
- **大文件能替换吗？** 流式替换代码已实现，100 MiB 算法落盘与读回校验通过；浏览器原生另存尚未端到端验收。
- **为什么导入的大文件不能直接替换另存？** 没有源句柄就无法可靠检查是否误选原文件，请用原生打开路径；不支持该能力的浏览器仍可查找。
- **支持任意正则或大文件编辑吗？** 普通模式正则有超时保护；大文件仅固定文本扫描和替换导出。
- **支持 GBK 吗？** 目前只支持 UTF-8。
- **刷新后正文还在吗？** 不在；只持久化主题与偏好，未保存内容会提醒。
- **主题能分享吗？** 自定义主题可导出 JSON，在另一实例导入；内置主题先复制再修改。
