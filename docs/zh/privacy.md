# 数据处理

当前源码的文本读取、编辑、对比、JSON、查找和替换在浏览器执行，没有上传正文的 fetch/XHR、业务后端或模型调用。依赖随构建打包；本地开发时 Vite 会建立热更新连接。生产资源加载仍有普通 HTTP 请求，不承诺“零网络”。

| 存储 | 内容 | 生命周期 |
| --- | --- | --- |
| notepad.themes.v1 | 自定义主题 JSON 列表 | 用户删除/清理站点数据前 |
| notepad.preferences.v1 | 当前主题 ID | 同上 |
| 页面内存 | 打开文档、文件引用、撤销历史、任务结果 | 页面关闭/刷新后丢失 |

正文不进入 localStorage，无草稿自动恢复。主题存储失败会提示并允许导出。文件读写权限只在用户选择文件时申请；替换输出不允许同一源句柄。网页由 GitHub Pages 提供静态资源；GitHub 会接收页面请求及常规连接信息。编辑器不上传文档正文；托管服务的日志由 GitHub 管理。
